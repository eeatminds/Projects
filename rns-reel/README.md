# RNS College of Nursing: 20 s admissions reel (Meta ads)

There are two cuts. Both are 1080×1920, 30 fps, H.264 High, AAC 48 kHz stereo, 20.0 s, about −14 LUFS, and ready for Reels and Stories placements.

| File | On-screen copy | Audio |
|---|---|---|
| `out/rns-reel-ml-9x16.mp4` | Malayalam | Music |
| `out/rns-reel-en-9x16.mp4` | English | Music + English voice-over (music ducks under the voice) |

`out/rns-reel-<lang>-thumbnail.jpg` is a cover frame taken at 1.6 s.

Every picture comes from rnsnursingcollege.com: real photos of the college, its lab and its hospital. Nothing is AI-generated.
- The music is an original track generated by `src/music.py`, so it has no licensing issues.
- The English voice-over is generated locally with [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0), using the `af_heart` voice. It is a generic narrator and doesn't imitate any real person.

The English lines were checked with speech-to-text on the final mix, and every line comes through, apart from the recogniser's own spelling of the names. Some wording was changed because of that check:
- "Hostel rooms" was heard as "hostile rooms".
- "WhatsApp us" was heard as "what's up us".

"Devika" and "Kerala" are forced to Malayali pronunciation (DAY-vi-ka, KAY-ra-la). The default US reading is dih-VIK-uh and KERR-uh-luh.

**Malayalam voice-over** isn't generated here. The two open Malayalam voices that run offline (Piper "meera" and "arjun") are trained on the IIT-Madras Indic TTS corpus, and their licence isn't clearly cleared for paid ads. Options:
1. **A Malayalam voice artist (recommended).** Record the five lines above, one file per line, and save them as `footage/vo-ml/s1.wav` … `s5.wav`. The build trims each file and places it at its window.
2. **ElevenLabs on a paid plan.** Eleven v3/v4 list Malayalam (ml). Generate each line and save it the same way.
3. A finished 20 s track also works: `footage/vo-ml.wav`.

A recorded English read can replace the generated one the same way (`footage/vo-en/…` or `footage/vo-en.wav`). `python3 build.py --no-vo` builds without voice-over.

## Swapping in real footage

The stills version is complete and can run as-is. To replace a slot with real footage, drop a clip into `footage/` and rebuild. Both cuts use it.

| File | Slot | Shooting notes |
|---|---|---|
| `footage/s1.mp4` | 0–3 s | Student talks to camera. Frame the face in the **lower half**, because the hook text sits on the top half. |
| `footage/s2.mp4` | 3–8 s | Skills lab about 2.5 s, then ward rounds in the parent hospital. The text cards stay on top. |
| `footage/s3.mp4` | 8–14 s | Alumna abroad, in Malayalam: where she studied and where she works. Her own audio is used, the voice-over skips this slot, and the music ducks underneath. A lower-third with her name replaces the portrait card. Keep the signed consent on file. For the English cut, consider a take in English or add subtitles. |
| `footage/s4.mp4` | 14–18 s | Hostel room, then the weekly Kerala food day. |
| `footage/music.wav` (or .mp3/.m4a) | 0–20 s | Optional: replaces the generated music bed. |

Clips can be any orientation. They are filled to 9:16, trimmed from their first frame to the slot length, and padded if they are short. Any slot whose clip has sound skips its voice-over line.

## Build

Requires:
- Python 3 with numpy and kokoro-onnx (`pip install kokoro-onnx`)
- Node with Playwright and Chromium
- ffmpeg

```bash
python3 build.py
```

This builds both cuts in about 3.5 minutes. The Kokoro model (about 350 MB) downloads to `models/` on first use and is git-ignored.
- `--lang ml|en` builds one cut.
- `--skip-render` reuses the rendered frames when only footage, music or voice-over changed.
- `--voice bf_emma` picks another Kokoro voice.

`src/reel.html` is the composition and can be opened in a browser; add `?lang=en` for the English copy. Call `seek(t)` from the console to scrub to any time. `node src/render.mjs --lang en --stills <dir> --at 1,5,9` renders single frames for review.
